FiltreTalent - Analyseur de CV Intelligent 🚀


FiltreTalent est une application web moderne conçue pour aider les candidats à optimiser leurs CV pour les systèmes de suivi des candidatures (ATS). En utilisant l'intelligence artificielle, l'application compare votre CV à une description de poste spécifique et vous fournit un score de compatibilité ainsi que des conseils d'amélioration concrets.

✨ Fonctionnalités

🔐 Authentification Sécurisée : Connexion via Puter.js.

📄 Analyse de CV : Support des fichiers PDF.

🤖 IA Intégrée : Analyse intelligente utilisant les modèles de langage de Puter.

📊 Score ATS : Évaluation de la pertinence de votre profil par rapport à l'offre.

💡 Conseils d'Amélioration : Recommandations personnalisées sur les mots-clés, la structure et le contenu.

📋 Historique : Suivez vos différentes candidatures et l'évolution de vos scores.

🛠️ Technologies Utilisées

Frontend : React 19 & React Router 7
Styling : Tailwind CSS
Backend & Services : Puter.js (Authentification, KV Store, Cloud File System, AI)
Traitement de fichiers : pdfjs-dist pour la conversion PDF vers Image.
Gestion d'état : Zustand

🚀 Démarrage Rapide

Installation
Clonez le dépôt et installez les dépendances :

npm install
Développement
Lancez le serveur de développement avec HMR :

npm run dev
L'application sera disponible sur http://localhost:5173.

Déploiement
Le projet est configuré pour être déployé facilement, notamment sur Vercel :

npm run build
📄 Utilisation
Connexion : Connectez-vous avec votre compte Puter.
Configuration : Entrez le nom de l'entreprise, le titre du poste et collez la description de l'offre.
Upload : Déposez votre CV au format PDF.
Analyse : L'IA traite votre document et vous affiche un rapport détaillé.
